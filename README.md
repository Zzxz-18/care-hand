# Care Hand｜家庭照護交接系統

手機優先的家庭照護交接 MVP，使用原生 HTML、CSS 與 JavaScript，無需安裝套件即可操作。

## 本機預覽

直接用瀏覽器開啟 `index.html`。未設定 LIFF ID 時，系統會以 Demo Mode 啟動，並使用虛構的林家照護資料。

## MVP 功能

- 首頁：今日紀錄、任務摘要、最近紀錄、未完成待辦與交接入口。
- 照護紀錄：新增、列表、檢視單筆內容；最新紀錄優先。
- 照護待辦：新增、編輯、指定日期時間及負責人、標記完成／重新開啟。
- 交接摘要：由現有紀錄及任務即時整理，不補造資料；可確認接手並記錄確認者與時間。
- 交接歷史：保存交接確認時的紀錄與任務快照，可回看交接來源。
- 家庭成員：展示模擬家庭成員，新增任務時可指定負責人。
- 資料介面：`storage.js` 將 UI 與 `localStorage` 分開，後續可替換成後端 API。

資料預設儲存在目前瀏覽器的 `localStorage`。在不同瀏覽器或裝置間不會同步；請勿輸入真實病歷或敏感個資。若瀏覽器不允許本機儲存，頁面仍能操作，但重新整理後暫存資料會消失。

## LIFF 設定預留

1. 在 `config.js` 將 `LIFF_ID` 設為 LINE Developers Console 提供的 LIFF ID。
2. 部署網站到 HTTPS 網址，並將該網址填入 LIFF app 的 Endpoint URL。
3. `liff.js` 會獨立載入 LIFF SDK 並呼叫 `liff.init()`；初始化失敗時回到 Demo Mode。
4. 目前 Demo 使用者選擇器只供展示。正式上線前，必須由可信任的後端驗證 ID token、家庭成員資格及每次資料存取權限。

不可把 Channel Secret、資料庫管理金鑰或其他服務端密鑰放入前端。LINE 推播尚未連接；介面不會假稱通知已送出。

## 主要檔案

- `index.html`：畫面結構與各頁面容器。
- `styles.css`：響應式版面與元件樣式。
- `app.js`：頁面切換、表單、任務狀態、交接與歷史操作。
- `storage.js`：模擬資料及本機資料存取介面。
- `config.js`：前端 LIFF ID 設定位置。
- `liff.js`：LIFF SDK 載入與初始化。

## 展示流程

1. 在首頁查看今日摘要。
2. 新增照護紀錄，確認首頁、紀錄列表與交接摘要同步更新。
3. 新增待辦並指定負責人和時間；編輯後標記完成，查看摘要中的任務狀態更新。
4. 到交接摘要選擇接手者並按「我已閱讀並接手」。
5. 到交接歷史查看確認者、確認時間及當時的紀錄快照。

右上角可以切換 Demo 使用者，以展示不同成員建立紀錄或接手的情境。重新載入會保留資料；若要還原起始展示資料，請在瀏覽器開發者工具清除 `care-hand-demo-v1` 這筆 localStorage。
